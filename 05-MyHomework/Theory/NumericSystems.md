# Системы счисления (ДЗ)

Материал: `NumericSystems.pdf` (материал учителя).

## Основные системы, используемые в сетях

| Система     | Основание | Цифры          | Где используется |
|-------------|-----------|----------------|-------------------|
| Двоичная    | 2         | 0, 1           | IP-адреса, маски, MAC на аппаратном уровне |
| Восьмеричная| 8         | 0-7            | Права доступа Unix (chmod), редко в сетях |
| Десятичная  | 10        | 0-9            | "Человеческое" представление IP (192.168.1.1) |
| Шестнадцатеричная | 16  | 0-9, A-F       | MAC-адреса, IPv6, дампы пакетов |

## Перевод между системами

**Из десятичной в двоичную** — деление на 2, остатки читаем снизу вверх:
```
203 / 2 = 101, остаток 1
101 / 2 = 50,  остаток 1
50  / 2 = 25,  остаток 0
25  / 2 = 12,  остаток 1
12  / 2 = 6,   остаток 0
6   / 2 = 3,   остаток 0
3   / 2 = 1,   остаток 1
1   / 2 = 0,   остаток 1
203(10) = 11001011(2)
```

**Из двоичной в десятичную** — сумма степеней двойки на позициях с 1:
```
11001011(2) = 128+64+0+0+8+0+2+1 = 203(10)
```

**Из десятичной в шестнадцатеричную** — деление на 16:
```
203 / 16 = 12, остаток 11 (B)
12  / 16 = 0,  остаток 12 (C)
203(10) = CB(16)
```

**Быстрый перевод двоичная <-> шестнадцатеричная** — группами по 4 бита:
```
1100 1011
 C     B    => CB(16)
```

## Пример: октет IP-адреса

Один октет IP-адреса — число от 0 до 255, то есть ровно 8 бит (2^8 = 256 значений).
`192.168.1.10` в двоичном виде:
```
192 = 11000000
168 = 10101000
1   = 00000001
10  = 00001010
```
